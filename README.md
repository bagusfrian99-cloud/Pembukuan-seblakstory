# Seblak Story Pembukuan v3.3.72

Proses pembelian bersama untuk menu Harus Dibeli.

- Pilih barang yang benar-benar akan dibeli.
- Cetak hanya barang terpilih langsung ke printer BLE.
- Setelah belanja, isi jumlah aktual dan harga per pack.
- Barang yang tidak dibeli tidak mengubah stok/pengeluaran.
- Harga pembelian baru tetap dapat diinput.
- Simpan semua pembelian sekaligus dengan metode Tunai/Non Tunai.
