PEMBUKUAN SEBLAK STORY - PWA

Isi:
- index.html
- style.css
- app.js
- manifest.json
- sw.js
- icon.svg

CARA PAKAI:
1. Upload seluruh isi folder ini ke hosting yang mendukung HTTPS.
2. Buka alamat index.html dari Chrome Android.
3. Pilih menu Chrome > Tambahkan ke layar utama / Install app.
4. Aplikasi akan tampil seperti aplikasi biasa dan dapat bekerja offline setelah pertama kali dibuka.

CATATAN:
PWA membutuhkan HTTPS agar Service Worker aktif (localhost juga bisa untuk pengujian).
